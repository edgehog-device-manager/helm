Next steps:

1. Generate an Admin API keypair (if you have not provided one already):

     openssl ecparam -name prime256v1 -genkey -noout > admin_private.pem
     openssl ec -in admin_private.pem -pubout > admin_public.pem

   The public key must match the one configured via backend.adminApi.publicKeyPem
   (or backend.adminApi.existingSecret).

2. Generate an admin token with the gen-edgehog-jwt tool from the Edgehog repository:

     ./tools/gen-edgehog-jwt -t admin -k admin_private.pem

3. Provision a tenant through the Admin API. Each Edgehog tenant maps 1:1 to an
   Astarte realm; see the deployment guide for the full request payload:

     https://docs.edgehog.io/deploying_with_kubernetes.html#creating-a-tenant-with-the-admin-api

4. Log into the frontend with your tenant slug and tenant token.
